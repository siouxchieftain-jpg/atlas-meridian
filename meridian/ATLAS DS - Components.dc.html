Components

The Fluent 2 web components ATLAS uses, shown with the ATLAS theme. Sizes, paddings and states are Fluent UI React v9 defaults. Each entry adds what ATLAS allows and forbids. Components ATLAS has no screen for yet are listed at the end.

Button

Starts an action. Five appearances, three sizes. Hover and press the examples.

Appearance
Sheen · guide surfaces only
Size
With icon, icon only, toggle, menu and split
Use in ATLASPrimary for the one system action a view exists for: Lagre notat, Send til DPS. Secondary for everything else. Subtle inside toolbars and panels. The primary goes first; see where buttons go.
ATLAS ruleSheen is for the one start action on a guide surface. A clinical choice is never a primary button. Henvis and Behold are equal secondary buttons, side by side, nothing pre-selected. Labels name the clinician’s action, never the system’s advice.

Textarea

Multi-line text, such as the consultation note and the rationale for a decision.

Dialog

A modal window over smoke. 24px padding, 8px corners, shadow 64. At most two buttons. The primary comes first, as Fluent places it to the left of other actions.
